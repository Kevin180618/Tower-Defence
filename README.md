# 🏰 Tower Defense Game

> A 3D Tower Defense game built with Unity and C#, featuring
> spline-based enemy movement, multiple towers, tower upgrades,
> projectile systems, wave management, and persistent progression.


## ⭐ Key Features

- Spline-based enemy movement
- 3 tower types with upgrade systems
- Wave-based enemy spawning
- Projectile combat
- Currency system
- Persistent tower upgrades
- Victory/Game Over systems
- Audio settings
